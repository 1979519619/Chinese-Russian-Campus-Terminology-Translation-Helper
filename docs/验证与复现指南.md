# 验证与复现指南

## 一键自动核验

从仓库根目录运行：

- Linux / macOS：`./scripts/verify-campus-mvp.sh`
- Windows PowerShell：`.\scripts\verify-campus-mvp.ps1`

脚本按顺序完成以下检查，全部通过时输出 `VERIFY_PASS`：

1. 依赖完整性：可编辑安装环境下 `pip check` 无损坏依赖
2. 模型集检查：本地 Argos 模型覆盖中/英/俄各翻译方向（`MODEL_SET_PASS`）
3. 单元测试：30 项无依赖的术语增强层测试（`Ran 30 tests ... OK`）
4. 真实模型评估：40 条术语全部按指定译法输出（40/40），并包含普通文本回归检查与隐私日志哨兵（日志不落请求正文）

核验通过后在 `artifacts/verification/` 生成带时间戳的 JSON 报告，可作验收证据留存。

## 启动与使用

- Linux：`./scripts/start-campus-mvp-linux.sh`
- Windows：`scripts\start-campus-mvp.cmd`

服务默认运行在 `http://127.0.0.1:5000`。翻译前勾选「校园术语库」开关（默认关闭），译文下方会展示命中术语、分类与出处。

## 断网运行

全部组件本地运行（Argos 离线模型，无外部翻译 API 调用），断网状态下自动核验与 Web 翻译均可正常工作。2026-10-02 已在干净 Ubuntu 虚拟机以全新克隆实测复现，含断网自动核验（VERIFY_PASS）与断网交互翻译。

## 只读词表

Web 界面提供「浏览词表」入口，可查看全部 40 条记录的源术语、指定译法、分类与出处标注（只读）。
