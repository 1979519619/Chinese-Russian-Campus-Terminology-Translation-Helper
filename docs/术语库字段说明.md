# 术语库字段说明

术语库文件：`libretranslate/glossaries/campus_zh_ru.json`，共 40 条记录，覆盖 20 组中俄双向校园术语（每组含一条 zh-Hans→ru 与一条 ru→zh-Hans 记录）。

## 字段一览

| 字段 | 含义 |
|---|---|
| `id` | 记录唯一标识（如 `term-0001-zh-ru`） |
| `source` | 源术语 |
| `target` | 指定译法 |
| `direction` | 适用方向：`zh-Hans_to_ru` 或 `ru_to_zh-Hans` |
| `category` | 分类：课程专业 / 教学管理 / 校园固定表达 |
| `source_ref` | 出处标注，当前统一指向 `ref:docs/术语出处参考.md` |
| `status` | 审核状态，当前全部为 `demo` |
| `priority` | 优先级权重，参与命中判定的固定比较顺序 |
| `updated_at` | 最近更新日期 |
| `aliases` | 别名列表（可为空） |

## 匹配与替换规则

- 精确字面匹配：不做模糊匹配与词形变化推断
- 多条记录同时命中时，按状态 → 术语长度 → 优先级 → `id` 的固定顺序比较，结果确定
- 俄语方向有词边界保护，避免子串误命中
- 命中术语先替换为唯一占位符、绕开翻译模型，译文生成后严格恢复为指定译法；恢复失败时安全回退并在响应中告警
- 响应附命中元数据（术语、指定译法、分类、出处、状态），Web 界面在译文下方展示

## 状态口径

当前 40 条记录均为 `demo`：即工程样例数据，用于验证机制有效性，不代表学校官方译法。正式启用前需逐条核实译法并更新 `status` 与 `source_ref`。
